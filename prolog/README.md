# Connect Four - Prolog

[![Prolog](https://img.shields.io/badge/Prolog-E61B23?style=for-the-badge&logo=prolog&logoColor=white)](https://www.swi-prolog.org/)

Implementation of Connect Four game in Prolog, a logic programming language based on formal logic and rules.

## Running the Game

**Prerequisite Installations:** 
- SWI-Prolog

**Command:**
```bash
swipl -q -s main.pl
```

## About

This implementation demonstrates Prolog's unique logic programming paradigm, including:
- Declarative programming with facts and rules
- Automatic backtracking and unification
- Pattern matching through logical inference
- Database-like querying capabilities  
- Constraint solving and search algorithms
- Non-procedural problem solving approach

The game showcases how logical reasoning can be applied to game mechanics, demonstrating Prolog's strength in AI and rule-based systems.
