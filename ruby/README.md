# Connect Four - Ruby

[![Ruby](https://img.shields.io/badge/Ruby-CC342D?style=for-the-badge&logo=ruby&logoColor=white)](https://www.ruby-lang.org/)

Multiple implementations of Connect Four game using Ruby and Ruby on Rails framework.

## Available Implementations

### Standard Ruby Implementation
**Prerequisite Installations:** 
- Ruby

**Command:**
```bash
ruby main.rb
```

### Ruby on Rails Web Application (rails)
**Prerequisite Installations:** 
- Ruby
- Ruby on Rails

**Commands:**
```bash
cd rails/ConnectFour
bundle install
rails server
```

## About

This collection demonstrates Ruby's elegance and the power of Rails framework:
- **Console**: Pure Ruby with expressive syntax and dynamic features
- **Web Application**: Full-featured web framework with convention over configuration

Features showcased:
- Dynamic, object-oriented programming with elegant syntax
- Metaprogramming and runtime flexibility
- Convention over configuration with Rails
- MVC architecture for web applications
- Active Record ORM for database interaction
- RESTful routing and web service development
