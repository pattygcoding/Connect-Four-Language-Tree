# Connect Four - C++ with Windows

[![C++](https://img.shields.io/badge/C++-00599C?style=for-the-badge&logo=c%2B%2B&logoColor=white)](https://isocpp.org/)

Implementation of Connect Four game in C++ with Windows-specific features and compilation.

## Running the Game

**Prerequisite Installations:** 
- G++ (Part of GCC)

**Command:**
```bash
g++ -o main.exe main.cpp -mwindows
./main.exe
```

## About

This implementation demonstrates C++ programming with Windows-specific features:
- Windows API integration for native Windows applications
- Object-oriented design with Windows-specific libraries
- Platform-specific compilation and linking
- Windows executable generation with GUI capabilities
- Cross-platform C++ programming considerations

The game showcases how C++ can leverage Windows-specific features while maintaining object-oriented design principles and modern programming practices.
