# Connect Four - Haskell

[![Haskell](https://img.shields.io/badge/Haskell-5e5086?style=for-the-badge&logo=haskell&logoColor=white)](https://www.haskell.org/)

Implementation of Connect Four game in Haskell, a statically typed purely functional programming language.

## Running the Game

**Prerequisite Installations:** 
- GHC (Glasgow Haskell Compiler)

**Command:**
```bash
ghc -o ConnectFour main.hs
./ConnectFour
```

## About

This implementation demonstrates Haskell's purely functional programming paradigm, including:
- Pure functions with no side effects
- Lazy evaluation and infinite data structures
- Strong static type system with type inference
- Monads for handling side effects and state
- Pattern matching and algebraic data types
- Higher-order functions and composition

The game showcases how pure functional programming can elegantly model complex game logic and state transitions.
