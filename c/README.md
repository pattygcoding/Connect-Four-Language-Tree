# Connect Four - C

[![C](https://img.shields.io/badge/C-00599C?style=for-the-badge&logo=c&logoColor=white)](https://www.gnu.org/software/gcc/)

Implementation of Connect Four game in C, a general-purpose procedural programming language.

## Available Implementations

### Standard C Implementation
**Prerequisite Installations:** 
- GCC

**Commands:**
```bash
gcc -o connect4 main.c
./connect4
```

### Windows Implementation
**Prerequisite Installations:** 
- GCC

**Commands:**
```bash
cd windows
gcc -o main.exe main.c -mwindows
./main.exe
```

## About

This implementation demonstrates C's fundamental programming concepts and system-level programming capabilities, including:
- Procedural programming with structured design
- Manual memory management with pointers
- Low-level system interaction and performance
- Portable code that compiles across platforms
- Direct hardware access and minimal runtime overhead
- Foundation for understanding computer systems

The game showcases how C's simplicity and power make it the foundation for system programming and performance-critical applications.
