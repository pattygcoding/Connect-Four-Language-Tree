Implementation of Connect Four game in C# using .NET Core with Windows Forms for desktop GUI application.

## Running the Game

**Prerequisite Installations:** 
- .NET Core SDK

**Command:**
```bash
dotnet run
```

## About

This implementation demonstrates C# desktop development with Windows Forms, including:
- Event-driven GUI programming with Windows Forms
- Visual controls and layout management
- User interaction through mouse and keyboard events
- Graphics programming and custom drawing
- Cross-platform desktop development with .NET Core
- Modern Windows Forms features and styling

The game showcases how Windows Forms enables rapid desktop application development with rich user interfaces while maintaining the power of C# and .NET.
