Implementation of Connect Four game in C# using .NET Core and Entity Framework for data persistence.

## Running the Game

**Prerequisite Installations:** 
- .NET Core SDK
- Entity Framework Core

**Command:**
```bash
dotnet build
dotnet run
```

## About

This implementation demonstrates C# development with Entity Framework integration, including:
- Object-Relational Mapping (ORM) with Entity Framework Core
- Database-first and code-first development approaches
- LINQ to Entities for database querying
- Migration and database schema management
- Data persistence and retrieval patterns
- Modern C# with async/await for database operations

The game showcases how Entity Framework simplifies database operations while maintaining type safety and performance in C# applications.
