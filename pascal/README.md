# Connect Four - Pascal

[![Pascal](https://img.shields.io/badge/Pascal-E3F171?style=for-the-badge&logo=pascal&logoColor=black)](https://www.freepascal.org/)

Implementation of Connect Four game in Pascal, a structured programming language designed for teaching programming concepts.

## Running the Game

**Prerequisite Installations:** 
- FPC (Free Pascal Compiler)

**Command:**
```bash
fpc main.pas
./main
```

## About

This implementation demonstrates Pascal's structured programming approach and educational value, including:
- Clear syntax emphasizing readability and structure
- Strong typing with explicit variable declarations
- Procedural programming with functions and procedures
- Block-structured code organization
- Educational foundation for programming concepts
- Cross-platform compatibility with Free Pascal

The game showcases how Pascal's emphasis on structured programming creates clear, maintainable code ideal for learning fundamental programming principles.
