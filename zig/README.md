# Connect Four - Zig

[![Zig](https://img.shields.io/badge/Zig-F7A41D?style=for-the-badge&logo=zig&logoColor=white)](https://ziglang.org/)

Implementation of Connect Four game in Zig, a general-purpose programming language designed for optimal performance and safety.

## Running the Game

**Prerequisite Installations:** 
- Zig compiler

**Command:**
```bash
zig build-exe main.zig
./main
```

## About

This implementation showcases Zig's modern systems programming features:
- Manual memory management with safety
- Compile-time code execution
- No hidden control flow or memory allocations
- Cross-compilation support
- Integration with C libraries
- Explicit error handling
- Optimized performance by default

Zig provides a balance between low-level control and high-level safety, making it excellent for performance-critical applications like games.
