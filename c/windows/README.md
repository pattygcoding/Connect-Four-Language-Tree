# Connect Four - C with Windows

[![C](https://img.shields.io/badge/C-00599C?style=for-the-badge&logo=c&logoColor=white)](https://www.gnu.org/software/gcc/)

Implementation of Connect Four game in C with Windows-specific features and compilation.

## Running the Game

**Prerequisite Installations:** 
- GCC

**Command:**
```bash
gcc -o main.exe main.c -mwindows
./main.exe
```

## About

This implementation demonstrates C programming with Windows-specific features:
- Windows API integration for native Windows applications
- Platform-specific compilation flags and libraries
- Windows executable generation (.exe)
- System-specific user interface elements
- Cross-platform C programming considerations

The game showcases how C can be adapted for specific operating systems while maintaining its core procedural programming principles.
