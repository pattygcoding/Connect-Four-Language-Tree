# Connect Four - Bash

[![Bash](https://img.shields.io/badge/Bash-4EAA25?style=for-the-badge&logo=gnu-bash&logoColor=white)](https://www.gnu.org/software/bash/)

Implementation of Connect Four game in Bash scripting language.

## Running the Game

**Prerequisite Installations:** 
- Bash (usually pre-installed on Unix-like systems)

**Command:**
```bash
chmod +x main.sh
./main.sh
```

## About

This implementation showcases shell scripting capabilities for creating interactive command-line games. It demonstrates Bash features such as:
- Interactive user input
- Control flow structures
- Array manipulation
- Text-based user interface

**Note:** This implementation is currently work in progress.
