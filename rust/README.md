# Connect Four - Rust

[![Rust](https://img.shields.io/badge/Rust-000000?style=for-the-badge&logo=rust&logoColor=white)](https://www.rust-lang.org/)

Implementation of Connect Four game in Rust, a systems programming language focused on safety, speed, and concurrency.

## Running the Game

**Prerequisite Installations:** 
- Rust Cargo

**Command:**
```bash
cargo build
./target/debug/connect-four
rm target/debug/connect-four
```

## About

This implementation demonstrates Rust's unique approach to systems programming, including:
- Memory safety without garbage collection through ownership system
- Zero-cost abstractions and high performance
- Fearless concurrency with thread safety guarantees  
- Pattern matching and algebraic data types
- Cargo build system and package manager
- Cross-compilation and minimal runtime overhead

The game showcases how Rust's ownership model prevents common programming errors while delivering C-level performance.
