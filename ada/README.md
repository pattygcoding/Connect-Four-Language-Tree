# Connect Four - Ada

[![Ada](https://img.shields.io/badge/Ada-02f88c?style=for-the-badge&logo=ada&logoColor=white)](https://www.adacore.com/)

Implementation of Connect Four game in Ada, a systems programming language designed for safety and reliability.

## Running the Game

**Prerequisite Installations:** 
- GNAT (Part of GCC)

**Command:**
```bash
gnatmake main.adb
./main
```

## About

This implementation demonstrates Ada's strong typing system, contract-based programming, and emphasis on reliability and safety. Ada's features such as:
- Strong static typing with range constraints
- Built-in exception handling
- Task-based concurrency model
- Design by contract principles

The game showcases how Ada's safety-first approach can be applied to game development while maintaining high performance and reliability.
