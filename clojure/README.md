# Connect Four - Clojure

Implementation of Connect Four game in Clojure, a dynamic Lisp dialect.

## Running the Game

**Prerequisite Installations:** 
- Java Development Kit (JDK)
- Clojure

**Command:**
```bash
clojure -M main.clj
```

## About

This implementation demonstrates functional programming concepts in Clojure, including:
- Immutable data structures
- Higher-order functions
- Recursion and functional composition
- Lisp syntax and macros
- Interactive REPL development

The game showcases how functional programming paradigms can be applied to game logic and state management.
