# Connect Four - JavaScript

[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

Multiple implementations of Connect Four game using various JavaScript frameworks and environments.

## Available Implementations

### HTML5 & CSS3 (html-css)
**Prerequisite Installations:** 
- Python (for HTTP server)

**Command:**
```bash
cd html-css
python -m http.server
```
Then visit http://localhost:8000/index.html

### MySQL Integration (mysql)
**Prerequisite Installations:** 
- Node.js
- MySQL

**Command:**
```bash
cd mysql
node main.js
```

### MongoDB & NoSQL (mongodb-nosql)
**Prerequisite Installations:** 
- Node.js
- MongoDB

**Command:**
```bash
cd mongodb-nosql
node main.js
```

### Next.js Framework (next)
**Prerequisite Installations:** 
- Node.js
- Next.js

**Command:**
```bash
cd next
npm run dev
```
Then visit http://localhost:3000/main

### Node.js Backend (node)
**Prerequisite Installations:** 
- Node.js

**Command:**
```bash
cd node
node main.js
```

### Vue.js Framework (vue)
**Prerequisite Installations:** 
- Node.js
- Vue CLI

**Command:**
```bash
cd vue
npm run serve
```
Then visit http://localhost:8080

### Vue.js with AI (vueai)
**Prerequisite Installations:** 
- Node.js
- Vue CLI

**Command:**
```bash
cd vueai
npm run serve
```
Then visit http://localhost:8080

## About

This collection demonstrates JavaScript's versatility across different environments and frameworks:
- Frontend web development with HTML/CSS
- Database integration with MySQL and MongoDB
- Modern React-based framework with Next.js
- Backend development with Node.js
- Component-based development with Vue.js
- AI-enhanced gameplay implementations
