# Connect Four - C# with .NET Core

[![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)](https://docs.microsoft.com/en-us/dotnet/csharp/)
[![.NET Core](https://img.shields.io/badge/.NET_Core-5C2D91?style=for-the-badge&logo=.net&logoColor=white)](https://dotnet.microsoft.com/)

Implementation of Connect Four game in C# using .NET Core framework.

## Running the Game

**Prerequisite Installations:** 
- .NET Core SDK

**Command:**
```bash
dotnet build
dotnet run
```

## About

This implementation demonstrates modern C# development with .NET Core, including:
- Cross-platform development with .NET Core
- Object-oriented programming with classes and inheritance
- Strong typing and compile-time error checking
- Automatic memory management with garbage collection
- Modern C# language features and syntax
- Console application development

The game showcases how .NET Core enables C# applications to run on multiple platforms while maintaining the language's enterprise-grade features.
