# Connect Four - Lua

[![Lua](https://img.shields.io/badge/Lua-2C2D72?style=for-the-badge&logo=lua&logoColor=white)](https://www.lua.org/)

Implementation of Connect Four game in Lua, a lightweight and embeddable scripting language.

## Running the Game

**Prerequisite Installations:** 
- Lua

**Command:**
```bash
lua main.lua
```

## About

This implementation demonstrates Lua's simplicity and flexibility as a lightweight scripting language, including:
- Simple syntax with powerful metaprogramming
- First-class functions and closures
- Prototype-based object orientation with metatables
- Automatic memory management with garbage collection
- Small footprint and high performance
- Easy embedding in applications

The game showcases how Lua's minimalist design and powerful features make it ideal for scripting and rapid prototyping.
