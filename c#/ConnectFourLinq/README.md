# Connect Four - C# with LINQ

[![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)](https://docs.microsoft.com/en-us/dotnet/csharp/)
[![.NET Core](https://img.shields.io/badge/.NET_Core-5C2D91?style=for-the-badge&logo=.net&logoColor=white)](https://dotnet.microsoft.com/)

Implementation of Connect Four game in C# using .NET Core with extensive LINQ usage for data querying and manipulation.

## Running the Game

**Prerequisite Installations:** 
- .NET Core SDK

**Command:**
```bash
dotnet build
dotnet run
```

## About

This implementation demonstrates C# development with LINQ (Language Integrated Query), including:
- LINQ to Objects for in-memory data querying
- Functional programming concepts with lambda expressions
- Method chaining and fluent syntax
- Deferred execution and query optimization
- Collection manipulation and transformation
- Modern C# syntax with expression-bodied members

The game showcases how LINQ enables elegant and readable data manipulation code while maintaining performance and type safety.
