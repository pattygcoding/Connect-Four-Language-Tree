# Connect Four - OCaml

[![OCaml](https://img.shields.io/badge/OCaml-EC6813?style=for-the-badge&logo=ocaml&logoColor=white)](https://ocaml.org/)

Implementation of Connect Four game in OCaml, a multi-paradigm programming language that emphasizes functional programming.

## Running the Game

**Prerequisite Installations:** 
- OCaml Compiler

**Command:**
```bash
ocamlc -o main main.ml
./main
```

## About

This implementation demonstrates OCaml's powerful type system and functional programming features, including:
- Strong static typing with type inference
- Pattern matching and algebraic data types
- First-class functions and closures
- Object-oriented programming capabilities
- Module system for code organization
- Efficient compilation to native code

The game showcases how OCaml's expressive type system can model complex game states while ensuring correctness at compile time.
