# Connect Four - Scala

[![Scala](https://img.shields.io/badge/Scala-DC322F?style=for-the-badge&logo=scala&logoColor=white)](https://www.scala-lang.org/)

Implementation of Connect Four game in Scala, a modern multi-paradigm programming language that runs on the JVM.

## Running the Game

**Prerequisite Installations:** 
- Scala

**Command:**
```bash
scala main.scala
```

## About

This implementation demonstrates Scala's fusion of object-oriented and functional programming, including:
- Object-oriented programming with traits and mixins
- Functional programming with immutable data structures
- Pattern matching and case classes
- Type inference with a powerful static type system
- Actor model for concurrent programming (Akka)
- JVM interoperability with Java libraries

The game showcases how Scala's expressive syntax and multi-paradigm approach enables elegant solutions that combine the best of both programming paradigms.
