# Connect Four - Python

[![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://python.org/)

Implementation of Connect Four game in Python, a high-level interpreted programming language known for its simplicity and readability.

## Running the Game

**Prerequisite Installations:** 
- Python

**Command:**
```bash
python main.py
```

## About

This implementation demonstrates Python's elegant syntax and powerful features, including:
- Clean, readable syntax with minimal boilerplate
- Dynamic typing with optional type hints
- Object-oriented and functional programming support
- Extensive standard library and ecosystem
- Interactive development with REPL
- Cross-platform compatibility

The game showcases how Python's focus on code readability and developer productivity makes it ideal for rapid development and prototyping.
