Implementation of Connect Four game in VB.NET using .NET Core with Windows Forms for desktop GUI application.

## Running the Game

**Prerequisite Installations:** 
- .NET Core SDK

**Command:**
```bash
dotnet run
```

## About

This implementation demonstrates VB.NET desktop development with Windows Forms, including:
- Event-driven GUI programming with Windows Forms
- Visual controls and drag-and-drop interface design
- User interaction through mouse and keyboard events
- Graphics programming and custom drawing capabilities
- Cross-platform desktop development with .NET Core
- VB.NET's RAD (Rapid Application Development) approach

The game showcases how VB.NET and Windows Forms enable quick desktop application development with rich user interfaces and intuitive visual design.
