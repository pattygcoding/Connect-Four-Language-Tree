# Connect Four - Kotlin

[![Kotlin](https://img.shields.io/badge/Kotlin-0095D5?style=for-the-badge&logo=kotlin&logoColor=white)](https://kotlinlang.org/)

Implementation of Connect Four game in Kotlin, a modern statically typed language that runs on the JVM.

## Running the Game

**Prerequisite Installations:** 
- Java Development Kit (JDK)
- Kotlin 

**Command:**
```bash
kotlinc main.kt -include-runtime -d main.jar
java -jar main.jar
```

## About

This implementation demonstrates Kotlin's modern language features and JVM interoperability, including:
- Null safety and smart casting
- Extension functions and higher-order functions
- Coroutines for asynchronous programming
- Data classes and sealed classes
- 100% interoperability with Java
- Concise syntax reducing boilerplate code

The game showcases how Kotlin combines the best of object-oriented and functional programming paradigms while maintaining full compatibility with the Java ecosystem.
