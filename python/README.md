# Connect Four - Python

[![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://python.org/)

Multiple implementations of Connect Four game using various Python frameworks and libraries.

## Available Implementations

### Standard Python Implementation
**Prerequisite Installations:** 
- Python

**Command:**
```bash
python main.py
```

### AI Implementation (ai)
**Prerequisite Installations:** 
- Python
- AI libraries (numpy, etc.)

**Command:**
```bash
cd ai
python main.py
```

### Django Web Framework (django)
**Prerequisite Installations:** 
- Python
- Django

**Commands:**
```bash
cd django
python manage.py runserver
```

### JSON Data Implementation (json)
**Prerequisite Installations:** 
- Python

**Command:**
```bash
cd json
python main.py
```

### Tkinter GUI Implementation (tkinter)
**Prerequisite Installations:** 
- Python
- Tkinter (usually included)

**Command:**
```bash
cd tkinter
python main.py
```

### IronPython Implementation (IronPython)
**Prerequisite Installations:** 
- IronPython
- .NET Framework

**Command:**
```bash
cd IronPython
ipy main.py
```

## About

This collection demonstrates Python's versatility across different domains and frameworks:
- **Console**: Standard Python with clean, readable syntax
- **AI/Machine Learning**: Integration with scientific computing libraries
- **Web Development**: Full-featured web applications with Django framework
- **Data Processing**: JSON handling and data manipulation
- **GUI Development**: Desktop applications with Tkinter
- **Cross-Platform**: IronPython integration with .NET ecosystem

Features showcased:
- Clean, readable syntax with minimal boilerplate
- Dynamic typing with optional type hints
- Object-oriented and functional programming support
- Extensive standard library and rich ecosystem
- Interactive development with REPL
- Cross-platform compatibility and framework integration
