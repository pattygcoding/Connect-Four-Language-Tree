# Connect Four - C#

[![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)](https://docs.microsoft.com/en-us/dotnet/csharp/)

Multiple implementations of Connect Four game using various C# frameworks and technologies.

## Available Implementations

### Basic C# Implementation
**Prerequisite Installations:** 
- CSC (C# Compiler)

**Commands:**
```bash
csc main.cs
./main.exe
```

### .NET Core Implementation (ConnectFour)
**Prerequisite Installations:** 
- .NET Core SDK

**Commands:**
```bash
cd ConnectFour
dotnet build
dotnet run
```

### .NET Core with Entity Framework (ConnectFourEF)
**Prerequisite Installations:** 
- .NET Core SDK
- Entity Framework Core

**Commands:**
```bash
cd ConnectFourEF
dotnet build
dotnet run
```

### .NET Core with LINQ (ConnectFourLinq)
**Prerequisite Installations:** 
- .NET Core SDK

**Commands:**
```bash
cd ConnectFourLinq
dotnet build
dotnet run
```

### .NET Core with Windows Forms (ConnectFourWPF)
**Prerequisite Installations:** 
- .NET Core SDK

**Commands:**
```bash
cd ConnectFourWPF
dotnet run
```

## About

This collection demonstrates C#'s versatility across different .NET frameworks and technologies:
- Object-oriented programming with strong typing
- .NET Core cross-platform development
- Entity Framework for database integration
- LINQ for data querying and manipulation
- Windows Forms for desktop GUI applications
- Modern C# language features and syntax

The implementations showcase how C# can be used for console applications, database-driven applications, and desktop GUI development.
