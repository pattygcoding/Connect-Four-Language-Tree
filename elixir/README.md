# Connect Four - Elixir

[![Elixir](https://img.shields.io/badge/Elixir-4B275F?style=for-the-badge&logo=elixir&logoColor=white)](https://elixir-lang.org/)

Implementation of Connect Four game in Elixir, a dynamic functional language built on the Erlang Virtual Machine.

## Running the Game

**Prerequisite Installations:** 
- Erlang
- Elixir

**Command:**
```bash
elixir main.exs
```

## About

This implementation demonstrates Elixir's powerful concurrency model and functional programming paradigms, including:
- Actor-based concurrency with lightweight processes
- Fault-tolerant design with supervision trees  
- Immutable data structures and pattern matching
- Functional programming with pipe operator
- Hot code swapping and distributed systems support
- "Let it crash" philosophy for error handling

The game showcases how Elixir's concurrency and fault-tolerance features can be applied to interactive applications.
