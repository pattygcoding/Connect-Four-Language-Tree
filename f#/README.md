# Connect Four - F#

[![F#](https://img.shields.io/badge/F%23-378BBA?style=for-the-badge&logo=f-sharp&logoColor=white)](https://fsharp.org/)

Implementation of Connect Four game in F#, a functional-first programming language that runs on .NET.

## Available Implementations

### .NET Core Console Implementation (ConnectFour)
**Prerequisite Installations:** 
- .NET Core SDK

**Command:**
```bash
cd ConnectFour
dotnet run
```

## About

This implementation demonstrates F#'s functional programming approach and .NET integration, including:
- Functional-first design with immutable data structures
- Pattern matching and discriminated unions
- Type inference and strong static typing
- Interoperability with the .NET ecosystem
- Pipe operator for composable functions
- Async workflows for concurrent programming

The game showcases how F#'s expressive syntax and functional paradigms can create clear, maintainable code while leveraging the power of the .NET platform.
