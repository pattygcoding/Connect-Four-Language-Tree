# Connect Four - PowerShell

[![PowerShell](https://img.shields.io/badge/PowerShell-5391FE?style=for-the-badge&logo=powershell&logoColor=white)](https://docs.microsoft.com/en-us/powershell/)

Implementation of Connect Four game in PowerShell, a task automation and configuration management framework.

## Running the Game

**Prerequisite Installations:** 
- PowerShell

**Command:**
```bash
./ConnectFour.ps1
```

## About

This implementation demonstrates PowerShell's scripting capabilities and object-oriented features, including:
- Object-based pipeline for data manipulation
- Cmdlets for system administration and automation
- .NET integration and access to .NET classes
- Cross-platform support (PowerShell Core)
- Advanced functions and modules
- Rich help system and tab completion

The game showcases how PowerShell's administrative scripting language can be applied to interactive console applications beyond system management.
