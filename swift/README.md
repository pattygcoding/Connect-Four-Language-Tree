# Connect Four - Swift

[![Swift](https://img.shields.io/badge/Swift-FA7343?style=for-the-badge&logo=swift&logoColor=white)](https://swift.org/)

Implementation of Connect Four game in Swift, a powerful and modern programming language developed by Apple.

## Running the Game

**Prerequisite Installations:** 
- Swift
- macOS or a virtual environment that can run Swift

**Command:**
```bash
swiftc main.swift -o main
./main
```

## About

This implementation demonstrates Swift's modern language features and safety-first design, including:
- Type safety with optionals and automatic reference counting
- Protocol-oriented programming and extensions
- Generics and advanced pattern matching
- Memory safety without garbage collection
- Interoperability with Objective-C and C libraries
- Cross-platform development capabilities

The game showcases how Swift's emphasis on safety and performance makes it suitable for system-level programming while maintaining developer-friendly syntax.
