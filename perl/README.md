# Connect Four - Perl

[![Perl](https://img.shields.io/badge/Perl-39457E?style=for-the-badge&logo=perl&logoColor=white)](https://www.perl.org/)

Implementation of Connect Four game in Perl, a high-level general-purpose programming language known for its text processing capabilities.

## Running the Game

**Prerequisite Installations:** 
- Perl

**Command:**
```bash
perl main.pl
```

## About

This implementation demonstrates Perl's flexible syntax and powerful features, including:
- Regular expressions for pattern matching and text processing
- Dynamic typing with scalar, array, and hash data types
- Context-sensitive behavior and implicit variables
- Extensive library ecosystem (CPAN)
- "There's more than one way to do it" philosophy
- Cross-platform scripting capabilities

The game showcases how Perl's expressive syntax and text processing strengths can be applied to interactive console applications.
