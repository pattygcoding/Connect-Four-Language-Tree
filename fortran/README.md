# Connect Four - Fortran

[![Fortran](https://img.shields.io/badge/Fortran-734F96?style=for-the-badge&logo=fortran&logoColor=white)](https://fortran-lang.org/)

Implementation of Connect Four game in Fortran, a high-performance programming language designed for scientific and numerical computing.

## Running the Game

**Prerequisite Installations:** 
- GFortran (part of GCC)

**Command:**
```bash
gfortran -o ConnectFour main.f90
./ConnectFour
```

## About

This implementation demonstrates Fortran's computational strengths and modern features, including:
- High-performance numerical computing capabilities
- Array-oriented programming with intrinsic functions
- Strong typing with user-defined types
- Coarrays for parallel programming
- Legacy compatibility with decades of scientific code
- Optimized compilation for mathematical operations

The game showcases how Fortran's focus on mathematical computation can be applied to algorithm-intensive game logic.
