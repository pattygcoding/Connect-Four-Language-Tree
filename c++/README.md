# Connect Four - C++

[![C++](https://img.shields.io/badge/C++-00599C?style=for-the-badge&logo=c%2B%2B&logoColor=white)](https://isocpp.org/)

Implementation of Connect Four game in C++, an object-oriented extension of C with modern programming features.

## Available Implementations

### Standard C++ Implementation
**Prerequisite Installations:** 
- G++ (Part of GCC)

**Commands:**
```bash
g++ -o connect4 main.cpp
./connect4
```

### Windows Implementation  
**Prerequisite Installations:** 
- G++ (Part of GCC)

**Commands:**
```bash
cd windows
g++ -o main.exe main.cpp -mwindows
./main.exe
```

## About

This implementation demonstrates C++'s powerful features and object-oriented programming capabilities, including:
- Object-oriented programming with classes and inheritance
- Templates for generic programming
- Standard Template Library (STL) for data structures
- RAII (Resource Acquisition Is Initialization) for memory management
- Multiple programming paradigms in one language
- High performance with zero-cost abstractions

The game showcases how C++ combines the efficiency of C with modern programming language features for complex application development.
