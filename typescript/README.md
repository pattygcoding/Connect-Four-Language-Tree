# Connect Four - TypeScript

Multiple implementations of Connect Four game using TypeScript with different frameworks.

## Available Implementations

### Angular Framework (angular)
**Prerequisite Installations:** 
- Node.js
- Angular CLI

**Command:**
```bash
cd angular
ng serve --open
```

### Node.js Backend (node)
**Prerequisite Installations:** 
- Node.js
- TypeScript

**Command:**
```bash
cd node
tsc main.ts
node main.js
```

## About

This collection demonstrates TypeScript's capabilities for building type-safe applications:
- **Angular**: Component-based frontend framework with dependency injection, routing, and comprehensive tooling
- **Node.js**: Server-side TypeScript development with static type checking

Features showcased:
- Static type checking
- Modern ES6+ features
- Object-oriented and functional programming paradigms
- Compile-time error detection
- Enhanced IDE support and refactoring
- Gradual adoption from JavaScript
