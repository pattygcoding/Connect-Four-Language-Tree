# Connect Four - Go

[![Go](https://img.shields.io/badge/Go-00ADD8?style=for-the-badge&logo=go&logoColor=white)](https://golang.org/)

Implementation of Connect Four game in Go (Golang), a statically typed compiled language designed for simplicity and efficiency.

## Running the Game

**Prerequisite Installations:** 
- Go

**Command:**
```bash
go run main.go
```

## About

This implementation demonstrates Go's core principles and features, including:
- Simple, clean syntax with powerful standard library
- Fast compilation and execution
- Built-in concurrency with goroutines and channels
- Strong typing with interface-based design
- Garbage collection with low latency
- Cross-platform deployment

The game showcases how Go's emphasis on simplicity and performance makes it ideal for building efficient, maintainable applications.
