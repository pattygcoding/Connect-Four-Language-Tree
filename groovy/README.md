# Connect Four - Groovy

[![Groovy](https://img.shields.io/badge/Groovy-4298B8?style=for-the-badge&logo=apache-groovy&logoColor=white)](https://groovy-lang.org/)

Implementation of Connect Four game in Groovy, a dynamic JVM-based programming language with static-typing capabilities.

## Running the Game

**Prerequisite Installations:** 
- Java Development Kit (JDK)
- Groovy

**Command:**
```bash
groovy Main.groovy
```

## About

This implementation demonstrates Groovy's flexible syntax and JVM integration, including:
- Dynamic and static typing capabilities
- Concise syntax reducing boilerplate code
- Seamless Java interoperability and library access
- Closures and functional programming features
- DSL (Domain Specific Language) capabilities
- Script execution without compilation

The game showcases how Groovy combines the power of the JVM with the flexibility of dynamic languages for rapid development.
