# Connect Four - COBOL

[![COBOL](https://img.shields.io/badge/COBOL-005CA5?style=for-the-badge&logo=cobol&logoColor=white)](https://www.ibm.com/products/cobol-compiler)

Implementation of Connect Four game in COBOL (Common Business-Oriented Language).

## Running the Game

**Prerequisite Installations:** 
- COBOL compiler (GnuCOBOL recommended)

**Command:**
```bash
cobc -x main.cob -o connect-four
./connect-four
```

## About

This implementation showcases COBOL's capabilities for creating interactive programs beyond traditional business applications. Features include:
- Structured programming with divisions
- Data description entries
- Procedural logic
- File handling capabilities
- Legacy language modernization

A unique demonstration of using a business-oriented language for game development.
