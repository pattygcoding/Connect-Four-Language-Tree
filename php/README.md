# Connect Four - PHP

[![PHP](https://img.shields.io/badge/PHP-777BB4?style=for-the-badge&logo=php&logoColor=white)](https://php.net/)

Implementation of Connect Four game in PHP, a server-side scripting language designed for web development.

## Running the Game

### Command Line Version
**Prerequisite Installations:** 
- PHP

**Command:**
```bash
php main.php
```

### Web Browser Version
**Prerequisite Installations:** 
- PHP

**Command:**
```bash
php -S localhost:8000
```
Then visit http://localhost:8000/main.php

**Note:** Web browser version is work in progress.

## About

This implementation demonstrates PHP's versatility beyond web development, including:
- Server-side scripting with command-line interface support
- Dynamic typing and automatic memory management
- Extensive standard library for various applications
- Cross-platform compatibility
- Easy integration with databases and web servers
- Rapid development and deployment capabilities

The game showcases how PHP can be used for console applications while maintaining its web development strengths.
