# Connect Four - V

[![V](https://img.shields.io/badge/V-5d87BF?style=for-the-badge&logo=v&logoColor=white)](https://vlang.io/)

Implementation of Connect Four game in V, a simple, fast, safe, compiled programming language.

## Running the Game

**Prerequisite Installations:** 
- V compiler

**Command:**
```bash
v run main.v
```

## About

This implementation showcases V's design principles and modern language features:
- Simple syntax inspired by Go
- Memory safety without garbage collection
- Fast compilation times
- Cross-platform support
- No null pointers or undefined behavior
- Immutable variables by default
- Built-in testing framework
- C interoperability

V aims to combine the simplicity of Go with the performance of C, making it ideal for systems programming and game development.
