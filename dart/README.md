# Connect Four - Dart

[![Dart](https://img.shields.io/badge/Dart-0175C2?style=for-the-badge&logo=dart&logoColor=white)](https://dart.dev/)

Implementation of Connect Four game in Dart, a client-optimized language for fast apps on any platform.

## Running the Game

**Prerequisite Installations:** 
- Dart SDK

**Command:**
```bash
dart run main.dart
```

## About

This implementation demonstrates Dart's modern language features and cross-platform capabilities, including:
- Strong typing with null safety
- Asynchronous programming with async/await
- Object-oriented programming with mixins
- Just-in-time (JIT) and ahead-of-time (AOT) compilation
- Cross-platform development support

The game showcases how Dart's balanced approach to performance and developer productivity makes it suitable for various applications.
