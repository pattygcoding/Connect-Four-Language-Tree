# Connect Four - TypeScript with Node.js

[![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![Node.js](https://img.shields.io/badge/Node.js-43853D?style=for-the-badge&logo=node.js&logoColor=white)](https://nodejs.org/)

Implementation of Connect Four game using TypeScript with Node.js for server-side development.

## Running the Game

**Prerequisite Installations:** 
- Node.js
- TypeScript

**Command:**
```bash
tsc main.ts
node main.js
```

## About

This implementation demonstrates server-side TypeScript development with Node.js, including:
- Type-safe JavaScript development with TypeScript
- Server-side application development with Node.js
- Static type checking and compile-time error detection
- Modern ES6+ features with backward compatibility
- Enhanced IDE support with IntelliSense and refactoring
- Gradual migration path from JavaScript to TypeScript

The game showcases how TypeScript brings the benefits of static typing to Node.js development while maintaining JavaScript's flexibility and ecosystem.
