# Connect Four - VB.NET

[![VB.NET](https://img.shields.io/badge/VB.NET-512BD4?style=for-the-badge&logo=.net&logoColor=white)](https://docs.microsoft.com/en-us/dotnet/visual-basic/)

Multiple implementations of Connect Four game using VB.NET with different UI frameworks.

## Available Implementations

### .NET Core Console (ConnectFour)
**Prerequisite Installations:** 
- .NET Core SDK

**Command:**
```bash
cd ConnectFour
dotnet run
```

### Windows Forms Application (ConnectFourWPF)
**Prerequisite Installations:** 
- .NET Core SDK

**Command:**
```bash
cd ConnectFourWPF
dotnet run
```

## About

This collection demonstrates VB.NET's capabilities across different application types:
- **Console Application**: Command-line interface with text-based gameplay
- **Windows Forms**: Desktop GUI application with visual game board

Features showcased:
- Object-oriented programming with VB.NET syntax
- .NET Framework integration
- Windows desktop application development
- Event-driven programming
- Visual Basic's readable, English-like syntax
- Cross-platform .NET Core compatibility
