# Connect Four - Nim

[![Nim](https://img.shields.io/badge/Nim-FFE953?style=for-the-badge&logo=nim&logoColor=black)](https://nim-lang.org/)

Implementation of Connect Four game in Nim, a statically typed compiled systems programming language.

## Running the Game

**Prerequisite Installations:** 
- Nim compiler

**Command:**
```bash
nim compile --run main.nim
```

## About

This implementation showcases Nim's unique features as a modern systems language:
- Python-like syntax with C-like performance
- Compile-time evaluation and macros
- Memory management with garbage collection
- Cross-platform compilation
- Interoperability with C/C++/JavaScript
- Metaprogramming capabilities

Demonstrates how Nim combines the ease of high-level languages with the efficiency of low-level programming.
