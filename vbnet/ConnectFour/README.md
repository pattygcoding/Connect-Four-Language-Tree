# Connect Four - VB.NET Core

[![VB.NET](https://img.shields.io/badge/VB.NET-512BD4?style=for-the-badge&logo=.net&logoColor=white)](https://docs.microsoft.com/en-us/dotnet/visual-basic/)
[![.NET Core](https://img.shields.io/badge/.NET_Core-5C2D91?style=for-the-badge&logo=.net&logoColor=white)](https://dotnet.microsoft.com/)

Implementation of Connect Four game in VB.NET using .NET Core for console application development.

## Running the Game

**Prerequisite Installations:** 
- .NET Core SDK

**Command:**
```bash
dotnet run
```

## About

This implementation demonstrates VB.NET console application development with .NET Core, including:
- Cross-platform development with .NET Core
- Object-oriented programming with VB.NET's readable syntax
- Strong typing and IntelliSense support
- Automatic memory management with garbage collection
- English-like syntax that emphasizes readability
- Console I/O and user interaction patterns

The game showcases how VB.NET's approachable syntax makes it ideal for rapid application development while maintaining the power of the .NET ecosystem.
